# Open-Source Contribution Guidelines (Step 147)

## 1. Code Style & Standards
- Follow PEP 8 guidelines.
- Enforce type hints on all public methods.
- Write unit tests for new features.

## 2. Pull Request Checklist
1. All unit tests pass (`python -m unittest discover -s tests -p "test_*.py"`).
2. Code formatted with Black and flake8 checked.
