# Security Policy & Vulnerability Disclosure

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities to security@opentrust.ai. Do NOT file public GitHub issues for security vulnerabilities.
We attempt to acknowledge reports within 24 hours and issue patches within 7 business days.
